# 4TECH
## 🛠️ Configuración de la Base de Datos

Para que el proyecto funcione correctamente, sigue estos pasos:

1. Asegúrate de tener **MySQL** (XAMPP/WAMP) activo.
2. Crea una base de datos llamada `pruebaslocal`.
3. Ejecuta el script SQL de las tablas (ubicado en la carpeta `/sql` o donde lo tengas).
4. Ve al archivo `src/main/java/Config/Conexion.java`.
5. Llena las variables `url`, `user` y `pass` con tus credenciales locales.

**Nota:** Por seguridad, las credenciales no se suben al repositorio.
